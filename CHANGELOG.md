## [1.1.4] - 2026-11-08

### Fixed

- **`b_grid experiment` stores the same result as `b_main`** ([#8](https://gitea.rmontanana.es/rmontanana/Platform/issues/8), [#9](https://gitea.rmontanana.es/rmontanana/Platform/issues/9)). Both programs now run a fold with the same function (`run_fold`, `src/main/FoldRun.cpp`) and build the result of a dataset with the same function (`build_partial_result`, `src/main/FoldResult.cpp`). Their JSON files are identical field by field except dates and times; `tests/parity/run_parity.sh` checks it. Before this release, `b_grid experiment`:
  - stored `confusion_matrices` as `[]` and no `confusion_matrices_train`;
  - stored the folds in the order the tasks arrived, so they could not be paired with `b_main` or with another run. They are now sorted seed × fold, in the order the seeds were given;
  - stored `notes` as `[]`; the notes now carry the `b_main` prefix `Seed: s Fold: f:`;
  - stored `score_train` as 0 and ignored `--no-train-score`;
  - **ignored `--score`**: it always computed accuracy, even when the file said `roc-auc-ovr`;
  - predicted with `predict()` instead of the argmax of `predict_proba()`;
  - did not accept `--graph` or `--generate-fold-files`.
- **A failing task stops `b_grid`.** An exception in a worker left the manager waiting forever, or let `mpirun` kill the job without saying which task failed. The worker now prints the task, dataset, seed, fold and message and calls `MPI_Abort`. BayesNet 1.4.3 throws where 1.4.2 returned NaN, so this is needed before running it with `b_grid`.
- **`--generate-fold-files` throws when it cannot write** the fold file (for instance, when `datasets_experiment/` is missing), instead of silently writing nothing.

### Changed

- **What the times measure, in both programs.** `times_train` is `fit` alone, without the train/test split. `times_test` is `predict_proba` of the test partition alone, without building `Scores` and the confusion matrix. Times are therefore lower than in earlier releases and are not comparable with them.
- **The confusion matrix of `Scores` is one `torch::bincount`** instead of a loop of `item<int>()` per instance. The counts are the same.
- **MPI transport of `b_grid`.**
  - `Task_Result` gains `seed`, `score_train`, `has_train`, `n_classes`, `notes_len` and `graph_len`.
  - The confusion matrices, the notes and the graph travel in messages that follow `TAG_RESULT` from the same worker: `TAG_CONFUSION`, `TAG_CONFUSION_TRAIN`, `TAG_NOTES` and `TAG_GRAPH`.
  - `b_grid search` leaves the new fields at 0 and sends nothing else.
- **Dependencies.** `bayesnet/1.4.3`, which fixes [BayesNet#48](https://gitea.rmontanana.es/rmontanana/BayesNet/issues/48): the boosted ensembles no longer keep the model AdaBoost rejects. A rejected first model gave NaN probabilities and always class 0. `pyclassifiers/1.0.6` is unchanged (`force=True`).
- `TestPlatform` expects Platform 1.1.4 and BayesNet 1.4.3.

### Tests

- New `TestFoldResult.cpp`:
  - seed × fold order with unsorted seeds, and rejection of missing, duplicated and unknown folds;
  - the vectorized confusion matrix against a plain count, with a class absent from the test partition, and the JSON format of `Scores::get_confusion_matrix_json(true)`;
  - the fields of the result: notes with their prefix, matrices only when discretized, and no `confusion_matrices_train` with `--no-train-score`.
- New `tests/parity/run_parity.sh` compares `b_main` and `mpirun -np 3 b_grid experiment` on iris, ecoli and diabetes. Six cases:
  - `XBAODE` and `XBA2DE` (with notes);
  - `--no-train-score`;
  - `roc-auc-ovr`;
  - `TANLd` on continuous data;
  - `--graph`.
  
  It also checks that a failing task stops `b_grid` and names the task.

## [1.1.3] - 2026-11-07

### Changed

- Dependencies: `bayesnet/1.4.2` and `pyclassifiers/1.0.6` (built against it). BayesNet 1.4.2 fixes [BayesNet#47](https://gitea.rmontanana.es/rmontanana/BayesNet/issues/47): the X family (`XA1DE`, `XA2DE`, `XBAODE`, `XBA2DE`) sized its probability tables with the training maxima instead of the `states` map Platform passes to `fit`, so a value present only in the test partition was read out of range — the segfault of `b_grid` with `XA1DE` on `splice`, and silent garbage elsewhere. Results only change where some feature had a value above its training maximum; the model versions move (`XA1DE`/`XA2DE` 1.0.1, `XBAODE` 0.9.8, `XBA2DE` 0.9.10) so results computed with the fix can be told apart.
- Since 1.1.2 (commit 2c78599): `bayesnet/1.4.1` and `pyclassifiers/1.0.5`, where `getNumberOfStates()` returns `long` (the number of probability cells for the X family); the experimental `ExpEnsemble` and `XSpode` follow the signature.
- `TestPlatform` expects Platform 1.1.3 and BayesNet 1.4.2.

## [1.1.0] - 2025-07-02

### Added

- **AdaBoost Implementation**: Complete multi-class SAMME AdaBoost classifier with optimization
  - Optimized AdaBoostPredict with 100 estimators as default
  - Enhanced predictProbaSample functionality
  - Full predict_proba support for probabilistic predictions
- **Decision Tree Classifier**: New base classifier implementation with comprehensive tests
- **XA1DE Model Family**: Extended Averaged One-Dependence Estimators
  - XA1DE, XBAODE, XSPODE variants with threading support
  - Complete integration with memory optimization
  - Prior probability computation in prediction
- **Wilcoxon Statistical Test**: Statistical significance testing for model comparison
- **Folder Management**: Enhanced file organization with folder parameter support across tools
  - Added folder parameter to b_best, b_grid, b_main, and b_manage
- **vcpkg Integration**: Package management system integration (now migrated to Conan)

### Enhanced

- **Grid Search System**: Complete refactoring with MPI parallelization
  - Grid experiment functionality with conditional result saving
  - Fixed smoothing problems and dataset ordering
  - Enhanced reporting and summary generation
- **Excel Reporting**: Advanced Excel export capabilities
  - ReportExcelCompared class for side-by-side result comparison
  - Enhanced formatting with colors and fixed headers
  - Automatic file opening after generation
- **Results Management**: Comprehensive result handling and validation
  - JSON schema validation for result format integrity
  - Improved console reporting with classification reports
  - Pagination support for large result sets
- **Statistical Analysis**: Enhanced statistical testing and reporting
  - AUC (Area Under Curve) computation and reporting
  - Confusion matrix generation and visualization
  - Classification reports with color coding

### Performance Improvements

- Optimized AdaBoost training and prediction algorithms
- Enhanced memory management in XA1DE implementations
- Improved discretization algorithms with MDLP integration
- Faster ROC-AUC computation for binary classification problems

### Developer Experience

- **Testing Framework**: Comprehensive test suite with Catch2
- **Build System**: Streamlined CMake configuration with dependency management
- **Documentation**: Enhanced project documentation and build instructions
- **Code Quality**: Refactored codebase with improved error handling and logging

### Bug Fixes

- Fixed predict_proba implementations across multiple classifiers
- Resolved grid search dataset ordering issues  
- Fixed Excel report formatting and column width problems
- Corrected time output formatting in various tools
- Fixed memory leaks and stability issues in model implementations
